SPACE SYNTAX / 空间句法

为什么它既是文化目的地，又是城市穿行节点？

采用与01圣马可、03锡耶纳一致的三层框架：城市网络（Angular Choice / Integration）→ 广场可视性（VGA / Isovist）→ 人群行为（Agent-based / Observation）。当前为基于真实平面的可检验研究方案，不是已经运行DepthmapX的定量结果。

01

城市网络 · Urban network

Flinders Street Station与Swanston Street带来强到达性，联通CBD街网、广场及Yarra河岸。需要建立实际可步行的路网，分别计算Angular Choice与Integration；铁路、车行道不可误作为行人通道。

02

视觉整合 · VGA

在开放广场、建筑入口与Atrium分别设置视域网格。建筑体量、玻璃边界、台阶及地形必须明确是否遮挡视线；室内外不应粗暴合并成同一二维可视面。

03

行动路径 · Movement

至少区分车站—文化机构、CBD—河岸、广场自由停留三类活动。用入口观察、穿行轨迹和无活动日停留分布验证网络模型，不能将运营活动人流直接归因于空间句法。

03 / EDGES · 边界立面

建筑与公共地面的关系

LAB与Bates Smart设计的文化建筑围绕广场组织；不规则建筑立面和多个入口形成非传统的城市围合。需要逐边核对建筑高度、首层开放度与全天候通道。

待补：四侧连续立面、底层功能、檐口高度、真实剖面及高宽比。缺乏测绘数据时不计算精确H/W。

四侧边界不是同一种街墙

城市入口 / Flinders Street

对面是Flinders Street Station，交通节点为广场提供大量到达与穿行；分析重点是道路断面、行人过街和广场入口的高差。

文化建筑 / Built edge

NGV Australia、ACMI等公共文化设施构成主要使用目的地；建筑表皮的视觉复杂性不应混同于首层实际可进入性。

室内街道 / Atrium

Atrium从Flinders Street一侧延伸至河岸方向，是全天候的公共通道，也是建筑边界转化为室内公共空间的关键。

河岸关系 / Yarra

研究从广场到河岸的可达性和视觉联系，而非把河景当作广场本身的直接开敞边界。

街墙檐口高度、建筑立面展开与实测剖面未取得；不提供推测性H/W。

04 / PUBLIC LIFE · 使用情况

从设计意图到真实使用

文化展览、节庆、公众集会与日常坐卧共享开放空间。研究需区分文化设施吸引的人流、自由停留的人群及运营活动的贡献。

观察框架

工作日/周末、白天/夜间、日常/活动分别记录：穿行、坐卧、聚集、消费与非消费使用；同时检查日晒、风、雨、无障碍和维护。

尚未取得系统性现场观察或独立人流统计，不作定量成功判断。

把活动照片与日常照片分开阅读

使用类型

穿行、等候、自由坐卧、餐饮消费、文化参观、节庆和集体观看分别记录。特别关注不消费也可停留的区域。

季节与气候

墨尔本日晒、风和降雨对开放广场影响明显；Atrium的全天候性构成补偿，但需用实际观察验证两者之间的使用分配。

运营与空间的边界

活动吸引力可能来自城市位置、文化机构与运营团队，不可全部归功于铺地或建筑形式。应比较无活动日和大型活动日。

05 / EVALUATION · 评价总结

空间机制与可迁移性

核心假设：不规则建筑群可通过公共地面和文化功能形成强烈的城市识别性。风险：活动成功不能单独证明日常微气候、无障碍与自主使用品质。

可迁移的设计策略

明确公共地面的空间主导因素，并把建筑、交通、地形、活动与运营纳入同一研究框架。

需要反证的判断

空间形式新颖不等于日常公共性强；对比建成前后与长期使用证据后再作最终评分。

设计转译

Federation Square提供的启示不是复制解构主义外立面，而是把文化功能、室内公共通廊、交通到达与开放广场作为连续的城市公共空间系统设计。需要进一步以真实剖面、日常使用观察与运营数据验证。

方法论：对现代案例增加“设计意图→建成空间→日常使用→运营变化→可迁移机制”的证据链；不在缺少实测证据时进行六维精确评分。

SPATIAL EVIDENCE / 空间证据审计

从“图像丰富”到“证据完整”

Figure Ground · 实虚关系

研究范围：以Flinders Street Station、Swanston Street、Russell Street、Yarra河为城市边界，比较广场人工平台与周边传统街块。观察：Federation Square不是传统街区中挖出的空洞，而是铁路上盖上新生成的城市公共地面。

证据：Level 0 / Level +1原始平面与城市底图。缺口：可核实比例的建筑轮廓底图尚未取得，故不制作伪精确Figure Ground。

Section · 剖面机制

研究问题：铁路结构平台如何支持广场、文化建筑和Atrium？城市街道、人工平台、室内通廊及河岸之间的标高如何连续？

证据：原始平面和遗产文件；研究剖面仅作为索引。缺口：有比例尺的完整剖面及坡度数据尚待核实。

Edges · 围合机制

对照：圣马可的连续柱廊、锡耶纳的连续街墙，与Federation Square的多栋文化建筑和开放通廊形成三种边界机制。

分析指标：建筑界面长度、可进入首层比例、视线穿透、坐靠边缘、遮雨连续性。未取得实测数据时不填数字。

Use · 公共性反证

四组观察：平日午间／傍晚；工作日／周末；活动／无活动；室外广场／Atrium。记录自由停留、消费停留、过境和活动参与。

反证条件：如果非活动日长期缺少停留、或舒适空间主要依赖商业消费，则不能仅凭节庆人流认定其公共性优秀。

六维判断：暂不赋分
