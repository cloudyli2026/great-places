# San Marco consolidated research package — 2026-11-07

A consolidated **six-chapter local HTML research atlas** has been generated and packaged for review in the conversation. Its sections are: dimensions, official-GIS Figure–Ground, sections, public life, historical layers, evidence and provenance.

## What is complete
- Bilingual editorial narrative, approximate published geometric values with attribution, source links and documented analytical questions.
- Local research webpage with actual-data-only ArcGIS JSON building-polygon viewer and file import.
- Source inventory and methodology for architectural sections, historical event occupation, public-ground concessions and field observation.
- JavaScript syntax check and ZIP integrity check passed.

## What is not yet complete
- No archived official building geometry; Venice municipal server could not be reached from the working environment. The site can fetch it in a browser or import the official JSON manually.
- No calibrated 1:200 cross-Piazza or Piazzetta–Molo architectural section; original drawing PDF geometry has not been inspected.
- No measured café seating permit polygons, event crowd polygons or direct behavioral observations.
- No deployed public production site or approved publication rights for external image assets.

The deliverable is therefore **v0.9 research package / working prototype**, **not a fully verified final measured drawing set**. No 1:1000 print scale or precise architectural dimensions are claimed. The ZIP is a conversation artifact; the full consolidated HTML has not been committed to GitHub in this step. Earlier research files and interactive GIS experiment are committed in this branch.
